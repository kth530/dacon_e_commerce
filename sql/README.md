# 고객 등급별 가치와 리텐션 분석: SQL

이 폴더는 최종 노트북의 MySQL 조회·검산 경로다. 노트북은 CSV와 Python으로
실행되므로 이 SQL 파일을 직접 호출하지 않는다.

`notebooks/02_data_preparation.ipynb`에서 `RUN_MYSQL_LOAD=True`로 실행해
`orders_master`, `onlinesales`, `customers`, `discount`, `marketing`, `tax`,
`rfm_scores`, `rfm_result`를 MySQL에 적재한 뒤 사용한다. 연결 정보는 프로젝트의
`.env`에 둔다. SQL은 MySQL 8 문법으로 작성했다.

기준 검산값은 상품라인 52,924행, 고객 주문 26,631건, 고객 1,468명,
상품매출 4,840,102.19달러, 배송비 238,987.60달러다. 다른 날 재방문은
734/1,468명, 관측 첫 구매월 +1개월 복귀는 130/1,362명이다.

| 순서 | 파일 | 역할 |
|---|---|---|
| 1 | `02_data_preparation.sql` | 원천·키·금액 검증, RFM 분류 대조, 고객 주문·활동·월·프로파일 뷰 생성 |
| 2 | `03_data_overview.sql` | 입력 컬럼과 결합 필드, 주문·월·RFM·등급·세그먼트 구성 조회 |
| 3 | `04_eda_validation.sql` | 다른 날 재방문·월 복귀, 등급별 상품매출, 같은 등급 내부 상태 비교 |

`01_problem_hypothesis.md`는 문제와 가설을 정의하는 문서라 SQL 대응 파일이 없다.

각 `-- name:` 블록은 독립된 문장이다. 02의 `create_*` 블록을 위에서 아래로
실행한 다음 03·04의 조회 블록을 실행한다. MySQL 클라이언트에서 파일을 통째로
실행하면 조회 결과가 차례로 나온다. 뷰 이름에는 `fa_` 접두사를 붙였고 기존
적재 테이블을 삭제하거나 교체하지 않는다.

R·F·M 분위 점수와 PCA 가중치는 Python에서 산출한다. SQL의 등급·세그먼트 CASE는
적재된 `rfm_scores`를 다시 분류해 `rfm_result`와 일치하는지 확인한다. 상품라인별
2자리 금액을 `DECIMAL`로 합산하고, 비율·중앙값의 표시용 반올림과 차트는 노트북에서
처리한다. 상품매출과 Monetary에는 배송비가 포함되지 않으며 고객 주문 키는
`(고객ID, 거래ID)`다. 월 복귀의 첫 구매월은 **2019년 관측 첫 구매월**을 뜻한다.
